# hyperscale-landscapes (Python pipeline)

The command-line tier of [Hyperscale Landscapes](https://github.com/jamiejcross/hyperscale-landscapes).
It builds multi-colour 3MF and single-colour STL terrain models for 3D printing,
with full data provenance. See the repository README for plain-language guidance.

    pip install "hyperscale-landscapes[uk]"
    hyperscale build --site auchtertool-cato
